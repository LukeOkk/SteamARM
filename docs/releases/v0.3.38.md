**Game sound about 65 ms behind instead of half a second, and Counter-Strike 2 always has sound.**

What was done:
- **Much lower sound delay.** The sound server SteamARM uses on the Mac (PulseAudio from Homebrew) gave the Mac's speakers and microphone a fixed 250 ms latency. Sound from games and Steam's voice chat therefore arrived roughly a quarter to half a second late. SteamARM now builds its own copy of the server with a fix, so the devices report their real latency. Counter-Strike 2 measured about 65 ms in total, and Steam's voice path about 90 ms (it was over 260 ms), with no dropouts. The setup builds it once (a few minutes); Homebrew's server is still used if the build fails.
- **Counter-Strike 2 and Windows games always find the sound server.** They run in a separate system folder and look for the sound connection there. SteamARM never created it itself, so it only existed by chance, and after the Mac's sound server restarted (for example after a reboot) Counter-Strike 2 was silent. Steam's start now creates it every time.

Everything in 0.3.37 is included: Windows games no longer stop Steam, Steam's voice and audio through PipeWire, Counter-Strike 2's own FSR drawn by MetalFX, real fullscreen without the Dock and the menu bar, MetalFX Temporal, MetalFX quality from 33 % to 100 %, and game windows you can resize.

**Tested on a real Mac (M4, macOS 27):** Counter-Strike 2's stream 46 ms of buffer plus 17 ms of device, with no underrun during a match. A test stream went from 275 ms to 52 ms. Audio script tests 10/10.

Update: drag the new SteamARM.app over the old one, open it, and click **Instalar** in the banner (the first setup also builds the sound server).
