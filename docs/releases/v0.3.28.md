**Fixes the update itself.** On a Mac that already had SteamARM's X server built, setting up 0.3.27 a second time (or any later update) failed while preparing the X server: the script asked of each patch separately whether it was already applied, and 0.3.27's new patch changes files of an older one. The X server and the graphics driver are now prepared from clean sources whenever their patches change.

If 0.3.27 stopped during **Instalar**, install this version and click **Instalar** again.

Everything in 0.3.27 is included: a game's picture stays in front of its window (no more white screen when clicking), real fullscreen at the display's own size with the menu bar and Dock hidden, and frames shown in step with the display.

**New measurement:** in Counter-Strike 2 at 1920x1080 with everything at its highest, the driver change that came with 0.3.27 (vertex work no longer waits for the previous pass) gave a median of 40 frames per second in a bot match against 27.5 with the old behaviour in the same session (one run each; earlier runs without it: 32-34).

**Tested on a real Mac (M4, macOS 27):** both build scripts run twice in a row (second run changes nothing), Vulkan tests 18/18, Python tests 151/151.

**Pre-release.** Still not confirmed by eye: whether the black flicker seen in fullscreen is gone (`LXRT_VK_MAILBOX_REAL=immediate` restores the previous presents to compare).
