**Sharp Counter-Strike 2 at your screen's resolution, and the frame limit and anisotropic filtering now work in Vulkan games.**

What was done:
- **Render scale: always 100 % unless you choose otherwise.** The automatic setting drew games at 59 % of the screen on an M4 and enlarged the whole picture, menus and text included, so Counter-Strike 2's text looked blurred even at 1080p. Games now draw at the screen's own resolution. To trade sharpness for frames, use the game's own FSR (it scales only the 3D scene, so text stays sharp; SteamARM draws it with MetalFX) or pick a scale yourself.
- **Frame-rate limit and anisotropic filtering for every game.** They used to reach only Direct3D games (DXVK/VKD3D); a native Vulkan game such as Counter-Strike 2 ignored them. Both now apply to Vulkan games too. Anisotropic filtering is a minimum: a game that asks for more keeps its own.
- **Lightning JIT** is now a choice under Settings → Pantalla → "Backend de la aplicación": native windows, with the x86 translator (FEX) set for speed -- code cached on disk between runs, lighter memory ordering, faster x87 maths. Experimental: a game that relies on strict memory ordering may misbehave; switch back to "Ventanas nativas" if so.

Everything in 0.3.46 is included (black screen after kills fixed, whole palm trees, Steam memory leak fixed).

**Tested on a real Mac (M4, macOS 27):** settings tests 15/15; Vulkan test programs pass with the frame limit and 16x anisotropic filtering forced on both drivers.

Update: drag the new SteamARM.app over the old one, open it, and click **Instalar** in the banner.
