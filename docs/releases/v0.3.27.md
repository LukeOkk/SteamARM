**A game's picture no longer disappears behind its own window, and games can fill the screen.** Found by playing Counter-Strike 2 (the native Linux build) by hand instead of only measuring it with bots.

What was done:
- **"Everything goes white when I move or shoot."** The picture of a Vulkan game is shown by a second window that SteamARM's X server keeps over the game's window. A click or a drag of the title bar brought the game's window in front of it for a moment (white, or black in fullscreen), and sometimes for good: the game then also dropped to about one frame per second. The picture now sits one window level above its window while the game is the one on top.
- **Real fullscreen.** The X screen is now the whole display (1920x1080 instead of 1920x1050), so games list and use the display's real size, a fullscreen window covers all of it, and the menu bar and the Dock are hidden while it does (they come back with Cmd-Tab).
- **Frames in step with the display.** Without V-Sync the game still never waits for the display, but what it shows now changes exactly at the display's refreshes, and a slow game (GPU-bound, 30-40 fps) has every frame shown instead of losing one in three.
- A further saving in the graphics driver (KosmicKrisp): vertex work of a pass no longer waits for the pass before it.

**Counter-Strike 2 at 1920x1080 fullscreen with everything at its highest** (4x MSAA, FSR off): 32-34 frames per second in a match with nine bots on an M4 (the GPU is the limit; with the game's medium settings and FSR Performance it was 86-93).

**Not confirmed:** a black flicker seen in fullscreen at these settings. The measurements say every frame is drawn, complete, and shown on a refresh, but that is not the same as seeing it. If it still flickers, start SteamARM with `LXRT_VK_MAILBOX_REAL=immediate` to compare, and tell us.

Everything in 0.3.26 is included.

**Tested on a real Mac (M4, macOS 27):** Vulkan tests 18/18 (four new), Python tests 151/151. Measurements: `benchmarks/stage53-fullscreen-layer-order.txt`.

**Pre-release.** `STEAMARM_X11_FULL_DISPLAY=0` gives the old X screen (without the strip under the menu bar).
