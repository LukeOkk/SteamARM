**Detener stops only the app it started, and the launcher tells you how an app ended.** Each app now runs in its own process group. Detener signals that group instead of killing every Linux process on the Mac. When a program exits on its own with an error, the launcher shows its exit code or signal instead of guessing from how long it ran.

Fixes:

- The memory guard no longer starts FEX's server every 5 s while only ARM64 programs run.
- Programs in the ARM64 root get sound: the one PulseAudio server now serves a socket in each guest root.
- An aarch64 program installed in the x86-64 Steam root is refused with a clear message instead of failing obscurely.
- `docs/ARCHITECTURE.md` described the x86 memory-ordering (TSO) mode backwards; corrected.

Groundwork for running Steam's ARM64 client (not usable yet):

- aarch64 programs run directly under the runtime, without FEX.
- `scripts/steamframe-image.py` reads Valve's Steam Frame recovery image on the Mac, with no VM and no btrfs-progs.
- `docs/CURRENT_STEAM_ENVIRONMENT.md` audits today's Steam environment for the ARM64 move.

Native arm64 Steam client (experimental, not usable yet):

- Valve's aarch64 Linux Steam client now starts under the runtime with no emulation. It downloads its update, installs and verifies it, and loads its UI libraries. It does not show its window yet: the main process aborts (`free(): invalid pointer`). Details are in `benchmarks/stage21-native-arm64-client.txt`.
- Runtime support added for it: 4 KiB-aligned ELF images and an optional 4 KiB guest page; x18 rewriting limited to real functions (it had corrupted OpenSSL's constant tables); x18 stores at large stack offsets; trampoline pools for very large libraries (libcef).
- `scripts/mkarmroot.sh` builds the aarch64 root it needs from Fedora packages.

Tested on a real Mac (M4, macOS 27) after merging: the x86 Steam client reaches its sign-in window in 85 s. tests/elf 37/37, tests/win 11/11 (D3D9/11/12 probes ~158–161 fps, 64- and 32-bit), sound and XInput in Steam's container 2/2, launcher core 17/17, audio 10/10.

**Pre-release.** Games are still not verified. Steam still runs as the x86 client under FEX, and Proton ARM64 does not run on macOS yet.

Update: drag the new SteamARM.app over the old one, open it, and click **Instalar** in the banner.
