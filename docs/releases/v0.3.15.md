**OpenGL (WineD3D) works again, now with OpenGL 4.5.** After 0.3.14's Setup restarted the window server, the Experimental **OpenGL (WineD3D)** option in **Configuración → Gráficos** could no longer start (Wine's Direct3D needs OpenGL 3.3 there, and the GPU path offered 3.2). SteamARM now gives it OpenGL 4.5: the Mac's GPU lacks only two rarely used data formats for the newer versions, and SteamARM tells the driver to go ahead without them. Direct3D 9 and 11 test programs draw again, 64- and 32-bit; only a program that uses one of those two formats could draw something wrong.

Everything in 0.3.14 is included.

**Tested on a real Mac (M4, macOS 27):** Vulkan and OpenGL 4/4 (OpenGL 4.5 programs draw correctly, x86-64 and i386); Windows programs through WineD3D 3/3 and DXVK; Python and launcher tests pass. Record: `benchmarks/stage39-wined3d-gl45.txt`.

**Pre-release.** Games are still not verified. Google Play Store has not been run.

Update: drag the new SteamARM.app over the old one, open it, and click **Instalar** in the banner.
