**Counter-Strike 2 now runs on MoltenVK too, with the right colours.**

What was done:
- **No more crash on MoltenVK.** Counter-Strike 2 closed itself when a match started with the MoltenVK driver. The game binds groups of textures with some empty slots, which Vulkan allows, and MoltenVK tried to read the empty ones. SteamARM now passes MoltenVK only the filled slots.
- **Correct colours on MoltenVK.** With MoltenVK, many Counter-Strike 2 materials lost their colour: a yellow chick came out white, red signs grey, and the scene looked cold. The game reads colour textures and shadow depths from the same list of textures, and MoltenVK's shader translator treated the whole list as depth, keeping only the red channel. SteamARM now gives the shadow reads their own copy of the list, so colours read all four channels again. On screen the colours now match KosmicKrisp.

Which driver to use: in Counter-Strike 2, KosmicKrisp is still faster. Measured on Dust2 with bots (maximum settings, MSAA 4x, FSR at 59 %, 3 minutes, two runs each): KosmicKrisp 84-85 fps on average (worst tenth 68-70), MoltenVK 75 fps (worst tenth 56-57). If you have KosmicKrisp selected in Settings, keep it for this game.

Everything in 0.3.42 is included.

**Tested on a real Mac (M4, macOS 27):** Counter-Strike 2 matches on MoltenVK with no crash; the colour fix rewrote 1288 of the game's 6242 shaders, all valid, and the user confirmed the colours on screen; the benchmarks above.
