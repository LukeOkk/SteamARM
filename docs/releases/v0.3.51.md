**About/version display and an Ultra Quality MetalFX spatial correction.**

- **Settings > Acerca de** displays the running app's version directly from
  `CFBundleShortVersionString`. Packaging uses that same value, and the
  release workflow checks that it matches the GitHub tag.
- **KosmicKrisp bilinear upscaling:** accept a scene occupying the whole of
  a smaller input texture, as well as a scene occupying part of a larger
  allocation. The former was silently skipped by the MetalFX spatial path
  used for Source 2's Ultra Quality bilinear pass. Keep the existing scale,
  blend, scissor, color-write and depth/stencil protections. The bilinear
  MetalFX log now confirms a successful encode, rather than a candidate
  that the scaler might subsequently refuse.
- **Regression coverage:** 77% input in both allocation layouts, the
  disabled path, blend/scissor exclusions, native resolution, and MoltenVK
  fallback. Check actual-encode logs as well as pixels: correct colors
  alone cannot establish that MetalFX ran.

Validated locally on Apple M4: isolated patched KosmicKrisp build, Vulkan
readbacks and existing render-pass, vertex-read, alpha/MSAA, pipeline-cache,
command-buffer resubmission and spatial MetalFX probes on both drivers.
Launcher compilation passed. These are executable probes; this release
does not claim that a full CS2 match has been revalidated or that every
Ultra Quality fallback has been eliminated.

Performance investigation: asynchronous MoltenVK queue submission did not
show a useful improvement in the clear/present probe, so no default was
changed. A 150% game FPS increase has not been demonstrated. Game quality
settings, FEX memory ordering and GPTK installation were not changed.

Everything in 0.3.50 is included.

Update the app, open it, and click **Instalar** to rebuild the patched driver.
An older running app or an unreconstructed driver does not include this fix.
