**The Metal HUD shows in games, and settings that did nothing or the opposite now do what they say.**

What was done:
- **Metal HUD works.** "Mostrar Metal HUD" loaded Apple's HUD in every game but it never appeared: the HUD needs a piece of macOS that SteamARM's runtime never ran for games drawn without a native window. It now runs it while the HUD is on. The HUD shows over games only, not over Steam's own windows.
- **Sharper Counter-Strike 2 with MetalFX temporal at 100 %.** That combination quietly ran every frame through MetalFX temporal without enlarging it, which softened the picture (blurry text) and cost frames. It is now off unless you turn on the new "MetalFX temporal también a resolución nativa" switch.
- **"SMC: full" now means full.** The strictest self-modifying-code mode for the x86 translator was being read as "none". Fixed.
- **Frame limit, anisotropic filtering and the Metal HUD apply to games only**, no longer to Steam's interface (the limit was throttling it).
- **Clearer labels:** the memory settings say what they really do ("Tope de memoria de las apps" is the safety limit for all apps; "VRAM que ven los juegos" is what games are told), settings that need a Steam restart say so, and Lightning JIT describes what it actually changes (code cache on disk, faster x87 maths).

Everything in 0.3.47 is included.

**Tested on a real Mac (M4, macOS 27):** the Metal HUD's per-frame statistics now register in a Vulkan test window (they never did before); settings, launcher and game-tool tests pass.

Update: drag the new SteamARM.app over the old one, open it, and click **Instalar** in the banner. Restart Steam afterwards so games get the new settings.
