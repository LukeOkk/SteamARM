**Android apps that run programs, and terminals: Termux works.** Termux installs its base packages, opens its shell, and `apt update` / `apt install` work (measured: a package downloaded, unpacked and run). Behind that, things any app may need:

- Apps can run programs. Every Android app runs under a security filter (seccomp), and with one in place the x86 emulator (FEX) failed to start any script or program the app launched ("Invalid or Unsupported elf file"). Fixed in FEX; this also covers apps that call out to a shell or a helper program.
- Terminals (pseudo-terminals), including a terminal's size and modes.
- Shared storage: `/sdcard` and each app's own folder on it, which Android refused to create until now ("Invalid mkdirs").
- Name lookups apps make with the "only if the network is configured" option, which failed with "No address associated with hostname" (apt was one such app; browsers and most apps were not affected).

**Android starts more reliably.** Two more ways Android's app launcher (the zygote) could stop at start-up are fixed, and when it does stop, the rest of Android now restarts with it instead of failing in a loop until the session is closed.

**Runtime:** programs that replace their own environment keep the runtime's settings; the runtime's start-up messages no longer end up in output an app captures; descriptors the runtime opens for itself never show up, even for a moment, where Android checks its open files.

**Tested on a real Mac (M4, macOS 27):** tests/elf 99/99; i386 18/18; Windows D3D9/11/12 probes 11/11; Vulkan device 2/2; ARM64 client checks 4/4; launcher core 35/35; the native display server 4/4; Python 137 OK; Android 87 passed with 2 expected failures (arm64 ART's heap; the headless boot's display wall), now with an app running programs under its security filter and shared storage. Termux: 7 of 7 starts with a working shell. Steam, started as the launcher starts it: native ARM64 sign-in window 8 of 8 (15-16 s); x86 main window 5 of 6 (100-101 s; once the 32-bit client crashed at the same place as in earlier versions, cause not yet known: start it again).
