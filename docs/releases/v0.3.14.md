**Fixes a Steam regression in 0.3.13.** In 0.3.13, stopping Steam left some of its helper processes running, and the next start could stay without a window. Stopping Steam now ends all of Steam again, and still leaves a running Android session alone. Measured: x86 Steam reached its main window 6 times in 6 after a stop each time.

**A rare crash in Windows programs' helper processes is fixed.** When the runtime prepared a signal for a program, it could, in a rare memory layout, write the signal's data over its own working memory and end the process (seen in Wine's background services). That can no longer happen.

**Diagnostics:** when the runtime cannot create a new process, it now says why, once, in the program's log.

Everything in 0.3.13 is included (fsync and esync, OpenGL on the GPU and WineD3D, Android sessions surviving a Steam stop).

**Tested on a real Mac (M4, macOS 27):** tests/elf 103/103; i386 18/18; arm64 4/4; Windows programs 14/14; Android 88 passed with 2 expected failures. Record: `benchmarks/stage38-opengl-zink.txt` (section 6).

**Pre-release.** Games are still not verified. Google Play Store has not been run.

Update: drag the new SteamARM.app over the old one, open it, and click **Instalar** in the banner.
