**FSR 3.1/4 MetalFX path, mouse-look capture, and release packaging.**

What changed:
- **FSR 3.1/4 to MetalFX temporal (experimental).** SteamARM builds its
  FidelityFX Wine built-ins, installs them into the x86 Steam root during
  setup, and routes supported Windows games through KosmicKrisp's temporal
  scaler. Recognized EasyAntiCheat and BattlEye markers and listed Steam app
  IDs leave the game's own FidelityFX DLLs untouched. Unknown anti-cheat
  systems are not detected automatically; compatibility remains in
  preparation and varies by game.
- **XQuartz mouse-look.** Relative pointer motion now remains available while
  a Wine game has captured the mouse.
- **Full releases from Actions.** The macOS workflow can publish this version
  as GitHub's latest release when dispatched with `prerelease=false`.

Everything in 0.3.49 is included.

Update: drag the new SteamARM.app over the old one, open it, and click
**Instalar** in the banner.
