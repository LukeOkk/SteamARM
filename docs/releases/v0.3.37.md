**Fix: starting a Windows game could stop Steam and everything else running in SteamARM.**

What was done:
- **Windows games no longer overload macOS's memory bookkeeping.** Each Wine process split its reserved memory into about 105,000 tiny pieces. Starting one Windows game with Wine's helper processes made about a million, and macOS slows to a crawl long before it runs out of them. SteamARM's safety watchdog then stopped every guest, Steam included, to protect the Mac. Wine's memory is now reserved in one piece. Starting a game now adds about 6,500 instead of about 960,000.
- Windows games also start a little lighter: Wine's 1.6 GB reservation is no longer filled with zeros by hand.

Everything in 0.3.36 is included: Steam's voice and audio through PipeWire, Counter-Strike 2's own FSR drawn by MetalFX, real fullscreen without the Dock and the menu bar, MetalFX Temporal, MetalFX quality from 33 % to 100 %, and game windows you can resize.

**Tested on a real Mac (M4, macOS 27):** Windows game tests 21/21 (the one that used to fail at every install now passes), runtime tests 110/110 (including a new one for large reservations).

Update: drag the new SteamARM.app over the old one, open it, and click **Instalar** in the banner.
