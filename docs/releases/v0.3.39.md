**Fixes found by a review of the last releases: leaving fullscreen, multiple displays, MetalFX for a game's FSR, and sound settings.**

What was done:
- **Leaving fullscreen restores the window again.** A window that left fullscreen (a video player, a game switching to windowed) could stay the size of the whole display, under a title bar, with its bottom cut off. It now goes back to its previous size.
- **Fullscreen on the display you choose.** A game moved to another display for fullscreen went fullscreen on the old one. It now uses the display it was moved to.
- **Fixed-size dialogs stay fixed.** Since 0.3.33, fixed-size game windows can be resized like Mac windows. Installer and launcher dialogs of a fixed size are no longer made resizable too.
- **Fewer Dock flickers.** When a game recreated its picture twice in a row, the Dock could flash back for a moment.
- **A game's FSR drawn by MetalFX is safer.** MetalFX now waits correctly before the picture goes to the screen. It no longer takes over a pass it would get wrong (a part of the picture, a layer of a texture). A game with a slightly different FSR setup now has its picture read from the right place. If MetalFX can't take a game's picture, SteamARM gives up on it once instead of retrying every frame. Changing **Filtro de escalado** now takes effect without clearing any cache.
- **"Rendimiento máximo" uses MetalFX Temporal again.** The 33 % preset asked MetalFX Temporal for slightly more than its 3x limit, so it fell back to a plain stretch. The picture is now never smaller than a third of the window.
- **Sound server swap keeps every connection.** When SteamARM switches the Mac's sound server to its own build, other SteamARM sessions keep their sound connection.

Everything in 0.3.38 is included.

**Tested on a real Mac (M4, macOS 27):** Counter-Strike 2 with its FSR drawn by MetalFX at about 100 frames a second, with the Dock hidden. A window leaving fullscreen was restored to 1280x720. Vulkan tests 33/33 (including a new case for the FSR fix), Windows tests 21/21, audio tests 15/15.

Update: drag the new SteamARM.app over the old one, open it, and click **Instalar** in the banner.
