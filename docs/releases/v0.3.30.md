**The mouse stays in the game while you aim, cut-out foliage draws correctly, exclusive fullscreen works, and MetalFX upscaling is automatic.**

What was done:
- **"The mouse leaves the window while I aim."** Games grab and hide the pointer for mouse-look; SteamARM's X server only confined its own idea of the pointer, while the Mac's real cursor kept moving and a click could land on another window. Now, while a game confines a hidden pointer, the Mac's cursor stays still in the middle of the game window and only the mouse's movement goes to the game — what native Mac games do. A visible cursor that a game confines stays inside the window. Cmd-Tab gives the mouse back at once.
- **The pale rectangle under the palm leaves on de_dust2.** With MSAA, leaves and other cut-out cards rely on alpha-to-coverage, which the KosmicKrisp graphics driver lost in several cases (the card was drawn as a solid rectangle). Fixed (driver patches 08 and 09), with a 29-case test.
- **"Pantalla completa" (exclusive fullscreen) left a black screen.** Asking for a display mode made the X server capture every display. A request for the display's own resolution now just works; a different resolution is refused instead of blacking out the screen.
- **MetalFX upscaling, automatic.** New setting **Escala de render** (default **Automático**): a game that covers the screen renders at the resolution this Mac's chip can drive (1280x720 on an M4 at 1080p) and SteamARM enlarges every frame with Apple's MetalFX. On KosmicKrisp MetalFX had silently been a plain bilinear stretch; driver patch 10 makes it real. Counter-Strike 2 at the highest settings: **46.5 fps instead of 29.5 at native resolution**, the same as the game's own FSR "quality" (45) but with Apple's upscaler on the whole picture. Turn the game's own FSR off. MetalFX Temporal is not possible this way (it needs the game's motion vectors).
- **Less stutter and less memory in KosmicKrisp** (patches 11-13): compiled shaders are now kept between launches (a pipeline that took ~160 ms takes 0.25 ms the second time; no compile stalls in the second match), and the driver keeps far less command memory (Counter-Strike 2 footprint 8.9 GB → 7.4 GB).

**Correction:** the notes of 0.3.29 said Counter-Strike 2 ran at 80 fps at the highest settings; that number was measured while the game's settings were being changed. At the highest settings at native 1080p this M4 runs it at about 30 fps; with the automatic render scale about 47.

Everything in 0.3.29 is included.

**Tested on a real Mac (M4, macOS 27):** Vulkan tests 27/27 (five new), Python tests 152/152, launcher tests 36/36, pointer confinement 2/2. Measurements: `benchmarks/stage55-confine-alpha-metalfx.txt`.

**If something misbehaves:** Escala de render "100 %" turns the upscaling off; `XQUARTZ_POINTER_CONFINE=0` turns the mouse confinement off; `KK_CMDBUF_PER_PASS=1` restores the driver's old command buffers.
