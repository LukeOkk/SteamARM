Result
------
MEASURED:
1. Valve's GitLab answers from the Mac: frame-public/lepton cloned; the
   GitHub mirror's 6135b53 is an ancestor of upstream main (0ea2492, v3.0.3)
   with the same tree. The earlier analysis could not reach it.
2. Darwin refuses PROT_EXEC on a mapping of an unsigned, unlinked temporary
   file (MAP_SHARED and MAP_PRIVATE: EPERM), which is what lxrun's memfd
   is; an anonymous region aliased with mach_vm_remap can be read-execute
   while the original is read-write, and code written through the original
   runs through the alias, including after a rewrite. Same result as linked
   and when signed with resources/lxrt.entitlements like build/lxrun.
   That is the shape of ART's dual-view JIT code cache.
3. Waydroid's OTA channel: 129 arm64 GAPPS and 153 VANILLA system builds,
   all on SourceForge; the uncertified-device page redirects to Google
   sign-in.
4. Build and tests on the Mac: make lxrt launcher rc 0; make
   test-launcher-core all passed; tests/elf/run.sh 70 passed, 0 failed.
