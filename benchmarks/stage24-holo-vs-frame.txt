Fixes to scripts/steamframe-image.py compare (VERIFIED IN SOURCE, tested)
-------------------------------------------------------------------------
- vercmp: a port of pacman's alpm_pkg_vercmp/rpmvercmp; rows say which side is newer and
  whether only the pkgrel differs.
- PROVIDES/REPLACES counterparts for one-side-only packages; a versioned REPLACES counts only
  inside its range. A first version of the dependency parser split unversioned names ("mesa"
  -> "m" + "esa") and so missed deckard-mesa-linux-aarch64 -> mesa; found on the real data
  (H11 before the fix gave 4 counterparts), fixed, and now tested.
- The report records each database (base name or redacted URL, bytes, sha256, package count);
  an extracted root is accepted in place of an inventory JSON; --json, --states; a zstd
  database decodes with the zstd command when the Python module is missing.
- inventory records PROVIDES, REPLACES and BUILDDATE per package (its Markdown is unchanged).
